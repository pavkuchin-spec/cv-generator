At Northstar Labs, redesigned checkout idempotency and retry handling, reducing API errors from 1.8% to 0.3%. Added OpenTelemetry service-level dashboards, trace sampling, and runbooks that cut median incident recovery time by 45%.

## Distributed systems

Led an event-driven billing workflow using Go, Kafka, PostgreSQL, and Kubernetes. Explicit event contracts, dead-letter handling, replay tools, and correlation identifiers support 8 million events per month across three services.

## API design and technical leadership

At Riverbend Systems, designed versioned REST APIs supporting 40+ customer integrations without a breaking-change incident during the recorded period. Introduced compatibility checks and lightweight design reviews across two squads while mentoring four engineers.
